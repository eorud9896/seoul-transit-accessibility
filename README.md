# seoul-transit-accessibility
서울시 생활인구와 대중교통 접근성을 활용한 교통 취약지역 분석
# 서울시 대중교통 접근 취약지역 분석

## 프로젝트 소개
서울시 생활인구와 대중교통 접근성을 활용하여
생활인구는 많지만 버스 및 철도 접근성이 상대적으로 낮은 지역을
250m 격자 단위로 발굴하는 프로젝트입니다.

본 프로젝트는 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」을 위해 진행합니다.

## 분석 목표
- 생활인구가 많은 지역 파악
- 500m 내 버스정류장 접근성 분석
- 1km 내 철도역 접근성 분석
- 대중교통 접근 취약점수 산정
- 교통 취약지역 도출 및 개선방안 제안

## 사용 데이터
- 서울시 250m 격자 생활인구
- 서울시 250m 격자 공간정보
- 서울시 버스정류소 위치정보
- 서울시 역사마스터 정보
- 행정동 코드정보

## 현재 진행상황
- 2026년 9월 7일 하루치 파일럿 분석 완료
- 버스 접근성 분석 완료
- 철도역 접근성 분석 완료
- 대중교통 접근취약점수 산정 완료
- 파일럿 TOP 10 도출 완료

- 평일 / 주말 비교
- 시간대별 분석

- 최종 취약지역 선정
- 정책 개선방안 제안
